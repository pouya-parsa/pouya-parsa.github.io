# VDA Citation Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an accurate, responsive citation section to the VDA paper page with a readable citation, arXiv source links, BibTeX, and accessible copy feedback.

**Architecture:** Extend the existing static VDA HTML and CSS with a page-native citation section rather than refactoring the separate Cloud Drive page. Add one small ES module whose only responsibility is copying the visible BibTeX text and reporting success or the manual-copy fallback.

**Tech Stack:** Static HTML5, CSS, browser Clipboard API, ES modules, Node.js 22 built-in test runner, existing Cheerio-based site audit.

## Global Constraints

- Treat <https://arxiv.org/abs/2607.28967> as the authoritative paper source.
- Use the exact author order: Pouya Parsa, Raoof Zare Moayedi, Seongjin Choi.
- Use arXiv identifier `2607.28967`, primary category `cs.CV`, year `2026`, and DOI `10.48550/arXiv.2607.28967`.
- Preserve the existing visible `Preprint · July 2026` venue line and unrelated page copy.
- Do not refactor the Cloud Drive citation implementation.
- Do not add dependencies, citation-format switching, downloads generated by the site, third-party widgets, new analytics events, or analytics-worker changes.
- Keep the readable citation and BibTeX usable without JavaScript.
- Follow red-green TDD for every production behavior.

      querySelector(selector) {
        return elements[selector] ?? null;
      },
    },
    navigatorImpl: {
      clipboard: {
        async writeText(value) {
          copied.push(value);
        },
      },

  await clickHandler();
  assert.deepEqual(copied, [bibtex]);

    citation: { textContent: bibtex },

    navigatorImpl: {},

  assert.equal(
    status.textContent,

- [ ] **Step 5: Implement the citation-copy behavior**

Replace the temporary exports in `scripts/visual-distribution-anchoring.mjs` with:

```js
export async function copyCitation({
  citation,
  status,
  navigatorImpl = globalThis.navigator,
} = {}) {
  try {
    const writeText = navigatorImpl?.clipboard?.writeText;
    if (typeof writeText !== "function") throw new Error("Clipboard unavailable");

    await writeText.call(
      navigatorImpl.clipboard,
      citation.textContent.trim()
    );
    status.textContent = "Citation copied.";
    return true;
  } catch {
    status.textContent =
      "Select the BibTeX text and copy it manually.";
    return false;
  }
}

export function initCitationCopy({
  documentImpl = globalThis.document,
  navigatorImpl = globalThis.navigator,
} = {}) {
  const button = documentImpl?.querySelector("#copy-citation");
  const citation = documentImpl?.querySelector("#bibtex");
  const status = documentImpl?.querySelector("#citation-status");
  if (!button || !citation || !status) return false;

  button.addEventListener("click", () =>
    copyCitation({ citation, status, navigatorImpl })
  );
  return true;
}

if (typeof document !== "undefined") initCitationCopy();
```
